# BB Comic Forge

Самостоятельная кузница комиксов для SillyTavern. Расширение собирает страницу комикса из одной картинки или нескольких панелей, сохраняет изображения через SillyTavern и вставляет готовый HTML-блок прямо в чат.

Comic Forge не требует sillyimages или SLAYimages. API, референсы, гардероб, AI-черновик, история и профили персонажей живут внутри самого расширения.

## Что умеет

- Генерирует комикс отдельными панелями или одной полной страницей.
- Собирает панели на тёплой комиксовой подложке с адаптивной сеткой.
- В ручном режиме показывает результат в превью кузницы и отправляет в чат по кнопке.
- Перегенерирует отдельные панели до отправки или после отправки.
- Сохраняет пользовательские стили и макеты рядом со встроенными.
- Всегда просит модель рисовать бабблы и SFX внутри изображения.
- Сохраняет референсы и активный гардероб отдельно для текущего бота/чата.
- Может прикладывать последние готовые картинки как визуальный контекст для новых страниц.
- Имеет отдельный профиль подключения для AI-черновика.
- Имеет автоматический режим: черновик из чата, генерация и отправка в чат одной цепочкой.
- Может сохранить текущий оформленный комикс из превью как один PNG.
- Хранит локальную историю последних комиксов.

## Быстрый старт

1. Открой `Extensions -> BB Comic Forge`.
2. В блоке `API генерации картинок` выбери провайдер, endpoint, API key и модель.
3. Нажми `Проверить`, чтобы убедиться, что соединение живое.
4. При необходимости добавь референсы персонажей и собери гардероб.
5. Открой кузницу кнопкой `Открыть кузницу`.
6. Опиши сцену сам или нажми `Черновик из чата`.
7. Проверь режим, макет, стиль и количество панелей.
8. Нажми `Сгенерировать страницу`.
9. Если нужно, перегенерируй отдельную панель кнопкой палитры.
10. Нажми `Отправить в чат`.

Если включить `Автоматически после ответа бота`, Comic Forge после нового сообщения персонажа сам соберёт черновик, запустит генерацию и отправит результат в чат по выбранному режиму отправки.

## Провайдеры картинок

Поддерживаются:

- OnlySQ ImaGen: `https://api.onlysq.ru/ai/imagen`
- Gemini / Nano Banana compatible endpoint
- OpenAI-compatible `chat/completions` image endpoint
- OpenAI-compatible `images/generations` endpoint
- Naistera `/api/generate`

Референсы-картинки работают в Gemini, OpenAI-compatible `chat/completions` и Naistera. OnlySQ ImaGen и OpenAI `images/generations` получают только текстовый промпт.

OpenAI-compatible endpoint можно указывать как базовый URL или сразу с `/v1`. Например, `https://api.example.com` и `https://api.example.com/v1` нормализуются автоматически.

## AI-черновик

Кнопка `Черновик из чата` делает структуру страницы: название, сцену, план панелей, реплики, SFX и номер панели с лёгким фан-сервисом.

Есть три режима:

- `Текущая модель SillyTavern` - самый простой вариант, использует `generateQuietPrompt`.
- `Отдельный OpenAI-compatible chat` - отдельный endpoint/key/model для JSON-черновиков.
- `Отдельный Gemini-compatible` - отдельный Gemini-compatible `generateContent`.

Если endpoint, key или model для черновика оставить пустыми, расширение попробует взять значения из основного API картинок. Это удобно, когда один и тот же прокси умеет и текст, и картинки.

Парсер черновика терпит лишний текст вокруг JSON, markdown-блоки и trailing comma. Если модель всё равно ломает формат, попробуй снизить температуру черновика или выбрать другую текстовую модель.

## Стили и макеты

Встроенные стили находятся в списке `Стиль`. Пользовательский стиль можно сохранить двумя способами:

- в настройках: `Страница по умолчанию -> Примеры и сохранение`;
- в кузнице: `Заготовки стилей и макетов -> Сохранить стиль`.

Теперь описание стиля пишется прямо в карточке сохранения. Поле `Дополнительные инструкции к генерации` остаётся для разовых правок промпта страницы.

Макет задаёт ритм страницы и aspect ratio панелей. Пример пользовательского макета:

```text
9:16, 1:1, 16:9, 3:4
```

Сетка адаптивная: на телефоне панели складываются в один столбец, а в чате и превью используются одни и те же CSS-правила.

## Референсы, гардероб и прошлые картинки

Референсы персонажей доступны для:

- `{{char}}`
- `{{user}}`
- `NPC 1-4`

Для каждого слота можно добавить картинку и текстовое описание. Описание полезно даже для API, которые не читают изображения.

Гардероб хранит вещи общей библиотекой, а активные образы привязывает к текущему боту/чату. Можно собирать полный сет или образ по частям: верх, низ, обувь, аксессуары, причёска.

Настройка `Картинок из истории` добавляет последние готовые изображения Comic Forge в визуальный контекст. Лимит считается по картинкам, а не по комиксам: если последний комикс состоит из четырёх панелей, он может занять до четырёх слотов контекста.

Когда этот контекст включён, много-панельная генерация идёт последовательно, чтобы новые панели могли видеть уже созданные панели той же страницы.

## Кнопки кузницы

В заголовке кузницы есть две разные кнопки:

- `Свернуть` - прячет окно, но не останавливает генерацию.
- `Закрыть` - закрывает окно. Если генерация идёт, расширение предложит свернуть вместо закрытия.

Плавающая кнопка возле чата показывает состояние: обычный запуск, генерация или готовый комикс.

## Сохранение PNG

Кнопка `Сохранить PNG` в превью пытается отрендерить текущую HTML-страницу комикса в одно изображение и сохранить его через `/api/images/upload`.

Это работает без внешнего сервера, но зависит от браузерного HTML-to-canvas через SVG `foreignObject`. Если браузер заблокирует такой рендер или какая-то картинка не загрузится, расширение покажет ошибку и оставит обычный HTML-комикс без изменений.

## Ограничения

- PNG-экспорт зависит от браузера и локальной доступности картинок. HTML-комикс остаётся основным и самым стабильным форматом.
- OnlySQ ImaGen и OpenAI `images/generations` не получают image-reference.
- Реальный процент генерации API обычно не отдаёт, поэтому прогресс показывает стадию, время и cooldown.
- Чем больше референсов и прошлых картинок, тем быстрее заполняется лимит изображений у провайдера.

## Консольные команды

```js
BBComicForge.open()
BBComicForge.settings()
BBComicForge.generateFromDraft(draft)
```

## Авторы и источники

- BB Comic Forge: BruniikBron / BB extensions.
- Идеи image workflow и референсов вдохновлены [sillyimages](https://github.com/0xl0cal/sillyimages) от 0xl0cal.
- Идея гардероба, NPC-слотов и часть UX-подходов вдохновлены [SLAYimages](https://github.com/wewwaistyping/SLAYimages) от Wewwa.
- В экосистеме SLAYimages также указаны вклады hydall, aceeenvw и других авторов подходов.
- OnlySQ ImaGen подключён по публичной документации OnlySQ.

Comic Forge не является форком sillyimages или SLAYimages и не требует их установки.
