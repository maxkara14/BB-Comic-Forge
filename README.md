# BB Comic Forge

Самостоятельная кузница комиксов для SillyTavern. Расширение генерирует страницу комикса, сохраняет панели как изображения SillyTavern и вставляет готовый HTML-блок прямо в чат.

Comic Forge не требует sillyimages или SLAYimages. API, референсы, гардероб, черновик кузницы и история живут внутри самого расширения.

## Что умеет

- Генерирует комикс отдельными панелями или одной полной страницей.
- Собирает страницу в HTML с рамкой, сеткой, бабблами и SFX.
- Сохраняет изображения через `/api/images/upload`.
- Показывает готовый комикс в превью кузницы и отправляет его в чат только по кнопке `Отправить в чат`.
- Позволяет перегенерировать готовую панель в кузнице после смены стиля.
- Сохраняет собственные стили генерации и макеты рядом со встроенными заготовками.
- Даёт выбрать, кто рисует бабблы: модель внутри картинки или HTML поверх панели.
- Может свернуть кузницу во время генерации и показать готовность на маленькой кнопке у чата.
- Сохраняет наборы референсов отдельно для текущего персонажа/бота.
- Позволяет очистить текущее превью, если в нём остались битые картинки или старый тест.
- Показывает стадию генерации, таймер и cooldown между запросами.
- Оставляет retry-placeholder, если отдельная панель упала.
- Сохраняет черновик кузницы после закрытия окна.
- Хранит локальную историю последних комиксов.
- Поддерживает референсы персонажей и текстовые описания NPC для API без image-reference.
- Имеет встроенный гардероб с сетами, частями одежды, аксессуарами и назначением на `{{char}}`, `{{user}}` или NPC.

## Провайдеры

- OnlySQ ImaGen: `POST https://api.onlysq.ru/ai/imagen`
- Gemini / Nano Banana compatible endpoint
- OpenAI-compatible `chat.completions` image endpoint
- OpenAI-compatible `images/generations` endpoint
- Naistera `/api/generate`

Референсы и картинки активных образов отправляются в Gemini, OpenAI `chat.completions` и Naistera. Для OnlySQ ImaGen и OpenAI `images/generations` они сейчас пропускаются.

OpenAI-compatible endpoint можно указывать как базовый URL или сразу с `/v1`. Например, `https://api.rout.my` и `https://api.rout.my/v1` оба нормализуются под OpenAI-совместимый формат. Для Gemini-compatible прокси можно указывать базу совместимого маршрута, например `https://api.rout.my/compatible`.

## Быстрый старт

1. Открой `Extensions -> BB Comic Forge`.
2. Выбери провайдер, вставь API key и нажми `Подключить`.
3. Выбери модель.
4. Загрузи референсы персонажей, если они нужны.
5. Открой гардероб и собери активные образы.
6. Нажми `Открыть кузницу`.
7. Опиши сцену или создай черновик из чата.
8. Выбери режим генерации: панели для качества или одна страница для экономии запросов.
9. Выбери режим бабблов: `Рисует модель` обычно выглядит естественнее, `HTML поверх картинки` проще править стилями.
10. Нажми `Сгенерировать страницу`.
11. Проверь превью. Если нужно, поменяй стиль и нажми кнопку палитры на панели для перегенерации.
12. Когда результат устраивает, нажми `Отправить в чат`.

## Стили и макеты

В `Страница по умолчанию -> Примеры и сохранение` есть встроенные примеры стилей и макетов. Они нужны как шпаргалка: можно посмотреть, как описан стиль, какие aspect ratio идут в макете, и сохранить свой вариант.

Свой стиль берётся из поля `Custom style`. После сохранения он появляется в общем списке стилей в настройках и в кузнице.

Свой макет задаётся списком aspect ratio, например:

```text
9:16, 1:1, 16:9, 3:4
```

Описание макета попадает в промпт как подсказка по ритму страницы. Это удобно для повторяемых форматов: вертикальная webtoon-страница, крупный финал, сетка из квадратов, драматичная первая панель и так далее.

В кузнице можно выбрать другой стиль уже после генерации и перегенерировать отдельную готовую панель кнопкой с палитрой. Комикс при этом остаётся в превью, пока ты сам не отправишь его в чат.

Кнопка `Свернуть` в заголовке кузницы прячет окно, но не останавливает генерацию. Маленькая кнопка Comic Forge у чата покажет спиннер во время работы и галочку, когда результат готов.

## Референсы

В блоке референсов можно загрузить изображения для:

- `{{char}}`
- `{{user}}`
- `NPC 1-4`

Эти изображения используются как визуальные якоря персонажей.

У каждого слота также есть поле описания. Оно добавляется в промпт как текстовый якорь, поэтому особенно полезно для NPC и для провайдеров, которые не умеют читать картинки-референсы.

Наборы референсов сохраняются по текущему персонажу/боту. Если переключиться на другой чат с другим ботом, Comic Forge загрузит отдельный набор вместо того, чтобы заставлять каждый раз перетирать старые картинки.

## Гардероб

Гардероб открывается из секции референсов. Он устроен как библиотека вещей и активный шкаф персонажа.

Можно сохранять:

- `Комплект` — полный сет одежды;
- `Верх`;
- `Низ`;
- `Обувь`;
- `Аксессуары`;
- `Причёску`.

У каждой вещи есть:

- название;
- категория;
- назначение: для всех, `{{char}}`, `{{user}}` или NPC;
- картинка;
- описание;
- теги для быстрого фильтра в библиотеке.

Кнопка `Описать` может заполнить описание по картинке. Сейчас она работает с провайдерами, которые умеют читать изображение и отвечать текстом: Gemini и OpenAI-compatible `chat.completions`.

Для каждого слота персонажа можно выбрать режим:

- `Сет` — основной полный образ плюс аксессуары и причёска;
- `По частям` — верх, низ, обувь, аксессуары и причёска отдельно.

При генерации Comic Forge добавляет описания активных вещей в промпт. Если выбранный API поддерживает референсы, картинки активных вещей прикладываются к запросу.

## Страница По Умолчанию

Панель `Страница по умолчанию` свернута, чтобы настройки не давили на новичков. Внутри находятся:

- режим генерации;
- количество панелей;
- cooldown между запросами;
- параллельность;
- макет;
- стиль;
- character lock;
- negative prompt;
- prompt для AI-черновика.

## История

Кнопка `История` показывает последние созданные комиксы. Там можно открыть комикс в предпросмотре, удалить одну запись или очистить историю полностью.

История хранится в настройках расширения и не является файловым менеджером. Браузерное расширение SillyTavern не может надежно открывать системные папки на компьютере, поэтому кнопка папки убрана.

## Ограничения

- Настоящий процент генерации API обычно не отдает, поэтому прогресс показывает стадию и время.
- Экспорт комикса в одну готовую картинку пока не реализован.
- Retry работает для упавших панелей. Готовые панели можно перегенерировать в кузнице до отправки в чат; в самом чате лишняя кнопка не показывается.
- Вставка в последнее сообщение есть как опция, но по умолчанию Comic Forge создаёт новое сообщение. Если последний элемент чата является сообщением пользователя, расширение безопасно создаст новое сообщение вместо склейки.

## Консольные команды

```js
BBComicForge.open()
BBComicForge.settings()
BBComicForge.generateFromDraft(draft)
```
