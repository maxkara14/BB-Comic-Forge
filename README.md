# BB Comic Forge

BB Comic Forge - самостоятельная кузница комиксов для SillyTavern. Расширение помогает собрать страницу комикса из текущей ролевой сцены: можно сгенерировать AI-черновик, поправить его вручную, получить отдельные панели или одну готовую страницу и отправить результат обратно в чат.

Главная идея простая: Comic Forge не пытается заменить ролеплей. Он берет уже сыгранную сцену, превращает ее в понятный comic-page draft и дает контролировать, что именно уйдет в модель генерации изображения.

## Возможности

- Standalone-кузница с ручной правкой сцены, персонажей, панелей, реплик, SFX, вставок, стиля и negative prompt.
- AI-черновик из контекста чата, карточки персонажа, persona пользователя и character lock.
- Два режима генерации: каждая панель отдельным запросом или вся страница одной картинкой.
- Профили подключения для генерации изображений.
- Отдельные профили подключения для AI-черновика.
- Наборы черновика: можно сохранять промпт черновика, режим, макет, стиль, character lock, панели, реплики, вставки, SFX и доп. инструкции.
- Переносимые пресеты Comic Forge с экспортом в JSON, проверкой перед импортом и применением без изменения подключений или текущей сцены.
- Отдельная библиотека пресетов с поиском, фильтрами, компактными карточками и быстрым управлением наборами.
- Референсы персонажа, NPC и пользователя с загрузкой файла или вставкой картинки из буфера обмена.
- Гардероб как общая библиотека вещей с отдельными надетыми образами для каждого чата.
- История сохраненных комиксов: в нее попадает то, что явно отправили в чат или сохранили как PNG.
- Просмотр итогового prompt изображения прямо в кузнице.
- Увеличение комикса в кузнице и в сообщениях чата.

## Быстрый старт

1. Открой `Extensions -> BB Comic Forge`.
2. В блоке `API генерации картинок` выбери провайдера, endpoint, API key и модель.
3. При необходимости сохрани подключение как профиль, чтобы быстро переключаться между моделями.
4. Настрой `AI-черновик`: текущая модель SillyTavern, сохраненный профиль SillyTavern, отдельный OpenAI-compatible endpoint или Gemini-compatible endpoint.
5. Открой кузницу кнопкой `Открыть кузницу`.
6. Нажми `Черновик из чата` или заполни страницу вручную.
7. Проверь режим, макет, стиль, character lock, панели, реплики и вставки.
8. Нажми `Сгенерировать страницу`.
9. Отправь комикс в чат или сохрани PNG, если результат нужен в истории.

## Подключения

### Генерация изображений

Поддерживаются:

- OnlySQ ImaGen;
- Gemini / Nano Banana compatible endpoint;
- OpenAI-compatible `chat/completions` image endpoint;
- OpenAI-compatible `images/generations` и `images/edits` endpoints;
- Naistera.

Для генерации изображений можно сохранять несколько профилей подключения. Профиль хранит выбранный тип API, endpoint, ключ, модель и связанные параметры провайдера. Это удобно, если нужно быстро переключаться между Nano Banana, Naistera, OpenAI-compatible прокси и другими вариантами.

Референс-картинки прикладываются только к тем провайдерам, которые умеют принимать изображения. Comic Forge не ограничивает их общее количество: в запрос попадают все успешно загруженные включенные референсы и активные картинки гардероба. Фактический лимит задают провайдер и выбранная модель; при его превышении их ошибка показывается без скрытого удаления части референсов.

В режиме OpenAI Images запрос без картинок идет через `images/generations`, а запрос с референсами — через `images/edits`. Если совместимый источник явно сообщает, что edit endpoint или image input не поддерживается, Comic Forge повторяет генерацию без файлов и оставляет в prompt текстовые описания референсов и гардероба. Использованный endpoint и количество прикрепленных файлов выводятся в консоль браузера без API-ключа и содержимого prompt.

### AI-черновик

Черновик может писать:

- текущая модель SillyTavern;
- выбранный сохраненный профиль SillyTavern;
- отдельный OpenAI-compatible chat endpoint;
- отдельный Gemini-compatible endpoint.

Профили подключения черновика общие для всех чатов. Выбор профиля сразу применяет режим, endpoint, ключ, модель и температуру. Если изменить поля вручную, профиль не перезаписывается сам: для этого нужно нажать `Сохранить`.

## Страница и черновики

`Страница по умолчанию` задает базу для новых черновиков и автогенерации: режим, отправку в чат, число панелей, макет, стиль, character lock, план панелей, реплики, вставки, SFX и дополнительные промпты.

Кузница синхронизируется с дефолтами по отдельным полям. Если в конкретном чате вручную поменять, например, макет или character lock, это станет ручной правкой только для текущего чата. Остальные поля продолжат следовать настройкам по умолчанию.

Наборы черновика нужны для разных подходов к странице: динамичный экшен, спокойный диалог, вертикальный webtoon, подробный anime draft и так далее. Набор не хранит конкретную текущую сцену, поэтому его можно применять в разных чатах.

### Переносимые пресеты

Кнопки `Экспортировать пресет` и `Импортировать пресет` доступны в настройках страницы и в тонкой настройке Кузницы. Экспорт создает версионированный файл `*.bbcf-preset.json` со следующими данными:

- режим генерации, отправка и число панелей;
- полный prompt выбранного стиля;
- полный макет с ритмом и соотношениями сторон;
- prompt AI-черновика;
- дополнительные инструкции и negative prompt;
- необязательная рекомендация по типу API, модели, размеру и качеству.

Перед импортом Comic Forge показывает состав файла. Можно только добавить пресет в список или сразу добавить и применить его. API key, endpoint, профили подключений, персонажи, референсы, гардероб, сцена, панели, реплики, вставки и SFX в переносимый файл не входят и при применении не очищаются.

Кнопка `Пресеты` в шапке быстрого запуска и Кузницы открывает отдельное окно, поэтому управление наборами не перегружает основные формы. В библиотеке можно искать и фильтровать личные и импортированные пресеты, применять их, просматривать содержимое, обновлять текущими настройками, переименовывать, дублировать, экспортировать и удалять. Новый универсальный пресет также можно создать прямо из текущей конфигурации. Плотность библиотеки переключается между 2, 4 и 6 колонками: окно подстраивается под выбранный вариант, а на небольшом экране число видимых колонок временно уменьшается автоматически. Выбор сохраняется между открытиями библиотеки.

## Prompt изображения

Блок `Prompt изображения` в кузнице показывает текстовый prompt, который Comic Forge собирает для модели картинки. Референс-картинки не отображаются в этом блоке как base64 или файлы: они прикладываются к запросу отдельно, если провайдер это поддерживает.

В режиме отдельных панелей можно копировать prompt каждой панели или все prompts сразу. В режиме одной картинки остается только копирование prompt страницы, потому что отдельных панельных запросов там нет.

Поле `Контекст сообщений из чата` используется для AI-черновика. В prompt изображения контекст чата попадает только если включить отдельный переключатель `Добавлять контекст сообщений в prompt изображения`. По умолчанию он выключен, чтобы не перегружать image prompt и не дублировать уже собранный черновик.

В режиме `Экономно: весь комикс одним запросом` общие блоки страницы, character lock, референсы, гардероб и контекст не размножаются внутри каждой панели. Они добавляются один раз, а план панелей остается компактным.

## Референсы и гардероб

Обычные референсы персонажа, NPC и пользователя привязаны к текущему чату. Их можно загрузить файлом или вставить из буфера обмена. К каждому рефу можно добавить имя и текстовое описание на случай, если провайдер не принимает изображения.

Гардероб работает иначе. Библиотека вещей общая для всех чатов, а то, что надето на персонажа, NPC или пользователя, сохраняется отдельно для конкретного чата. Вещи можно добавлять файлом или вставкой из буфера, описывать, тегировать, редактировать и назначать как полный сет или по частям.

При отправке Comic Forge объединяет все включенные референсы персонажей с картинками активного гардероба и не обрезает итоговый список. Если конкретный API или модель допускает меньше изображений, запрос завершится их обычной ошибкой — уменьшить число активных референсов нужно в настройках чата или гардероба.

Картинки референсов сохраняются в хранилище SillyTavern, в папку `/user/images/bbcf_refs`. В настройках Comic Forge хранит ссылки на эти файлы и текстовые описания. Если сами файлы удалить из `user/images`, превью станут битыми и восстановить их можно только из бэкапа.

Кнопка `Восстановить` в гардеробе помогает найти гардеробные картинки, которые остались в файлах, но потеряли запись в библиотеке. Если файл еще лежит в `/user/images/bbcf_refs`, Comic Forge может вернуть его как восстановленный образ.

## История и превью

История не заполняется каждой пробной генерацией. В нее попадают только комиксы, которые пользователь явно решил сохранить:

- отправил комикс в чат;
- нажал `Сохранить PNG`.

Из истории можно открыть сохраненный комикс, удалить отдельную запись, очистить историю и отправить выбранный комикс в чат. Это удобно, если нужно сравнить несколько удачных вариантов, не засоряя историю всеми промежуточными попытками.

Комиксы, отправленные в чат, получают кнопку увеличения. На мобильном это помогает открыть страницу поверх чата и рассмотреть ее крупнее.

## Ограничения

- Максимум 6 панелей.
- Максимум 6 параллельных генераций.
- Максимум 3 прошлые картинки из чата в визуальном контексте.
- Количество обычных и гардеробных референсов не ограничивается расширением, но может ограничиваться провайдером или моделью.
- PNG-экспорт зависит от браузера и доступности картинок в превью.
- Буфер обмена с картинками зависит от браузера и разрешений страницы.
- API обычно не отдает настоящий процент генерации, поэтому прогресс показывает стадию и время.

## Консоль

```js
BBComicForge.open()
BBComicForge.settings()
BBComicForge.generateFromDraft(draft)
```

## Авторы и источники

- BB Comic Forge: BruniikBron / BB extensions.
- Идеи image workflow и референсов вдохновлены [sillyimages](https://github.com/0xl0cal/sillyimages) от 0xl0cal.
- Идея гардероба, NPC-слотов и часть UX-подходов вдохновлены [SLAYimages](https://github.com/wewwaistyping/SLAYimages) от Wewwa.
- В экосистеме SLAYimages также указаны вклады hydall, aceeenvw и других авторов подходов.
- OnlySQ ImaGen подключен по публичной документации OnlySQ.

Comic Forge не является форком sillyimages или SLAYimages и не требует их установки.
