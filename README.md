# BB Comic Forge

BB Comic Forge - самостоятельная кузница комиксов для SillyTavern. Расширение собирает страницу комикса из текущего чата, помогает подготовить AI-черновик, генерирует одну полную страницу или отдельные панели и вставляет готовый HTML-комикс обратно в чат.

Можно работать вручную: открыть кузницу, поправить сцену, панели, реплики, стиль и запустить генерацию. Можно включить автоматический режим: после ответа персонажа расширение возьмет настройки по умолчанию, подготовит черновик, сгенерирует страницу и отправит ее в чат.

## Возможности

- Генерация одной страницы или отдельных панелей.
- AI-черновик из текущего чата с отдельным подключением к текстовой модели.
- Профили подключения черновика: endpoint, API key, модель, режим и температура сохраняются глобально.
- Наборы черновика: можно сохранять и применять режим, макет, стиль, описание персонажей, план панелей, реплики, вставки, SFX и промпты.
- Умная синхронизация страницы по умолчанию с кузницей: поля следуют дефолтам, пока их не изменили вручную в конкретном чате.
- Раздельные черновики и ручные правки для разных чатов.
- Референсы персонажей, NPC и пользователя сохраняются в рамках текущего чата.
- Гардероб хранит общую коллекцию вещей, но активные надетые образы сохраняются отдельно для каждого чата.
- Пользовательские стили и макеты.
- Перегенерация отдельных панелей.
- История последних комиксов и сохранение превью как PNG.

## Быстрый старт

1. Открой `Extensions -> BB Comic Forge`.
2. В блоке API выбери провайдера картинок, endpoint, API key и модель.
3. При необходимости настрой `AI-черновик`: выбери подключение SillyTavern, OpenAI-compatible или Gemini-compatible.
4. Сохрани профиль подключения черновика, если хочешь быстро переключаться между разными моделями.
5. Открой кузницу и нажми `Черновик из чата` или заполни поля вручную.
6. Проверь режим, макет, стиль, описание персонажей, панели и реплики.
7. Нажми `Сгенерировать страницу`.
8. Отправь результат в чат, когда превью устраивает.

## Страница по умолчанию

`Страница по умолчанию` задает базу для новых черновиков и автогенерации: режим, отправку в чат, число панелей, макет, стиль, описание персонажей, план панелей, реплики, вставки, SFX и дополнительные промпты.

Кузница синхронизируется с этими настройками по полям. Если в конкретном чате вручную поменять, например, макет или описание персонажей, это поле станет ручной правкой только для текущего черновика. Остальные поля продолжат следовать странице по умолчанию.

Кнопка сброса возвращает дефолтные значения страницы, включая описание персонажей и поля набора черновика. API, референсы, гардероб и история при этом не трогаются.

## Наборы черновика

Набор черновика сохраняет не только текстовые промпты, но и основные параметры перед формированием черновика:

- prompt для AI-черновика;
- режим генерации и отправки;
- число панелей, макет и стиль;
- описание персонажей;
- план панелей, реплики, вставки и SFX;
- дополнительные инструкции и negative prompt.

Набор не сохраняет конкретную сцену и не затирает уже написанный сюжет. Его удобно использовать как быстрый пресет для разных подходов: обычная страница, динамичный экшен, вертикальный webtoon, спокойная диалоговая сцена и так далее.

## AI-черновик

Черновик может использовать:

- текущую текстовую модель SillyTavern;
- отдельный OpenAI-compatible chat endpoint;
- отдельный Gemini-compatible endpoint.

Профили подключения общие для всех чатов. Выбор профиля сразу применяет режим, endpoint, ключ, модель и температуру, но изменение полей не перезаписывает профиль автоматически. Для обновления профиля нужно нажать кнопку сохранения.

Для OpenAI-compatible API можно вписать модель вручную. Если `/models` у провайдера недоступен, подключение не должно ломать настройку: список моделей просто останется пустым.

## Провайдеры картинок

Поддерживаются:

- OnlySQ ImaGen;
- Gemini / Nano Banana compatible endpoint;
- OpenAI-compatible `chat/completions` image endpoint;
- OpenAI-compatible `images/generations` endpoint;
- Naistera.

Картинки-референсы передаются только тем провайдерам, которые умеют их читать. Для OnlySQ ImaGen и OpenAI `images/generations` используется текстовое описание.

## Режимы

`Качественно: каждая панель отдельно` делает отдельный запрос на каждую панель. Это дороже и медленнее, но обычно дает больше контроля.

`Экономно: весь комикс одним запросом` просит модель сразу нарисовать всю страницу. Это быстрее и дешевле по запросам, но модель сама отвечает за раскладку внутри картинки.

Параллельность работает для генерации панелей. Если задана пауза между запросами, генерация идет последовательно, потому что пауза иначе теряет смысл.

## Стили, макеты и контекст

Стили можно выбирать из списка или сохранять свои. Поле дополнительных инструкций добавляется поверх выбранного стиля как разовая правка, а не как отдельный сохраненный стиль.

Макеты задают ритм страницы и aspect ratio панелей. Пользовательский макет можно записать так:

```text
9:16, 1:1, 16:9, 3:4
```

Референсы персонажа, NPC и пользователя сохраняются отдельно для текущего чата. Гардероб работает иначе: сама библиотека вещей общая, а выбранные надетые образы привязаны к чату и не надеваются автоматически в новом диалоге. Контекст прошлых сообщений и изображений можно ограничить в настройках, чтобы не перегружать запросы.

## Ограничения

- Максимум 6 панелей.
- Максимум 6 параллельных генераций.
- Максимум 3 прошлые картинки в визуальном контексте.
- PNG-экспорт зависит от браузера и доступности картинок в превью.
- API обычно не отдает настоящий процент генерации, поэтому прогресс показывает стадию и время.

## Консоль

```js
BBComicForge.open()
BBComicForge.settings()
BBComicForge.generateFromDraft(draft)
```

## Авторы и источники

- BB Comic Forge: BruniikBron / BB extensions.
- Идеи image workflow и референсов вдохновлены [sillyimages](https://github.com/0xl0cal/sillyimages) от 0xl0cal.
- Идея гардероба, NPC-слотов и часть UX-подходов вдохновлены [SLAYimages](https://github.com/wewwaistyping/SLAYimages) от Wewwa.
- В экосистеме SLAYimages также указаны вклады hydall, aceeenvw и других авторов подходов.
- OnlySQ ImaGen подключен по публичной документации OnlySQ.

Comic Forge не является форком sillyimages или SLAYimages и не требует их установки.
