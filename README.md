# BB Comic Forge

BB Comic Forge - самостоятельная кузница комиксов для SillyTavern. Расширение собирает комикс из одной полной страницы или нескольких отдельных панелей, показывает результат в превью и вставляет готовый HTML-комикс в чат.

Можно работать вручную: собрать черновик, поправить сцену, выбрать стиль и нажать генерацию. А можно включить автоматический режим, и кузница сама начнёт делать комикс после нового ответа бота.

## Что есть сейчас

- Генерация одной страницей или отдельными панелями.
- Адаптивная комиксовая подложка для превью и вывода в чат.
- AI-черновик из текущего чата.
- Автогенерация после ответа бота.
- Отдельное подключение для модели черновика.
- Референсы персонажей и гардероб с привязкой к текущему боту/чату.
- Пользовательские стили и макеты.
- Дополнительные инструкции к генерации поверх выбранного стиля.
- Бабблы и SFX рисуются самой моделью внутри картинки.
- Перегенерация отдельных панелей.
- История последних комиксов.
- Сохранение оформленного превью как PNG.

## Быстрый старт

1. Открой `Extensions -> BB Comic Forge`.
2. В блоке API выбери провайдер, endpoint, API key и модель.
3. Нажми `Проверить`.
4. При необходимости добавь референсы и гардероб.
5. Открой кузницу.
6. Заполни сцену вручную или нажми `Черновик из чата`.
7. Проверь режим, макет, стиль и количество панелей.
8. Нажми `Сгенерировать страницу`.
9. Отправь результат в чат, когда превью устраивает.

Если включить `Автоматически после ответа бота`, Comic Forge после нового сообщения персонажа подтянет настройки страницы по умолчанию, соберёт черновик, запустит генерацию и отправит результат в чат по выбранному режиму отправки.

## Режимы

`Качественно: каждая панель отдельно` делает отдельный запрос на каждую панель. Это дороже, но обычно даёт больше контроля и качества.

`Экономно: весь комикс одним запросом` просит модель сразу нарисовать всю страницу. Это быстрее и дешевле по запросам, но модель сама отвечает за раскладку внутри картинки.

Параллельность работает для генерации панелей. Если задана пауза между запросами, генерация идёт последовательно, потому что пауза иначе теряет смысл.

## AI-черновик

Черновик может использовать:

- текущую текстовую модель SillyTavern;
- отдельный OpenAI-compatible chat endpoint;
- отдельный Gemini-compatible endpoint.

Для OpenAI-compatible API можно вписать модель вручную. Если `/models` у провайдера недоступен, кнопка подключения не должна ломать настройку: список просто останется пустым.

Для OnlySQ текстовых моделей можно использовать OpenAI-compatible режим с endpoint:

```text
https://api.onlysq.ru/ai/openai
```

## Провайдеры картинок

Поддерживаются:

- OnlySQ ImaGen;
- Gemini / Nano Banana compatible endpoint;
- OpenAI-compatible `chat/completions` image endpoint;
- OpenAI-compatible `images/generations` endpoint;
- Naistera.

Картинки-референсы передаются только тем провайдерам, которые умеют их читать. Для OnlySQ ImaGen и OpenAI `images/generations` используется текстовое описание.

## Стили, макеты и контекст

Стили можно выбирать из списка или сохранять свои. Описание сохраняемого стиля пишется прямо в карточке сохранения. Поле `Дополнительные инструкции к генерации` - это разовая добавка поверх выбранного стиля, а не отдельный сохранённый стиль.

Макеты задают ритм страницы и aspect ratio панелей. Пользовательский макет можно записать так:

```text
9:16, 1:1, 16:9, 3:4
```

Референсы, описания персонажей и активный гардероб сохраняются отдельно для текущего бота/чата. Контекст прошлых картинок можно ограничить в настройках, чтобы не перегружать запросы.

## Ограничения

- Максимум 6 панелей.
- Максимум 6 параллельных генераций.
- Максимум 3 прошлые картинки в визуальном контексте.
- PNG-экспорт зависит от браузера и доступности картинок в превью.
- API обычно не отдаёт настоящий процент генерации, поэтому прогресс показывает стадию и время.

## Консоль

```js
BBComicForge.open()
BBComicForge.settings()
BBComicForge.generateFromDraft(draft)
```

## Авторы и источники

- BB Comic Forge: BruniikBron / BB extensions.
- Идеи image workflow и референсов вдохновлены [sillyimages](https://github.com/0xl0cal/sillyimages) от 0xl0cal.
- Идея гардероба, NPC-слотов и часть UX-подходов вдохновлены [SLAYimages](https://github.com/wewwaistyping/SLAYimages) от Wewwa.
- В экосистеме SLAYimages также указаны вклады hydall, aceeenvw и других авторов подходов.
- OnlySQ ImaGen подключён по публичной документации OnlySQ.

Comic Forge не является форком sillyimages или SLAYimages и не требует их установки.
